# Stationery Request Form

A corporate stationery request portal built as a single-page HTML application. Employees can submit requests for office supplies through a clean, responsive form.

## Features

- Responsive corporate-style UI
- Stationery item selection and quantity input
- Department and employee details capture
- Form validation
- No backend required — runs entirely in the browser

## Usage

Open `stationery_request_form.html` in any modern web browser:

```bash
# Windows
start stationery_request_form.html

# macOS
open stationery_request_form.html
```

Or serve it with a local static server:

```bash
npx serve .
```
